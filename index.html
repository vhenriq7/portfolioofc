Parte 02 · Conceitos principais · Endrius

Três tecnologias.
Uma infraestrutura.

Linux como base, Samba para compartilhamento em rede e Rsync para sincronização inteligente — uma infraestrutura completa e sem custo de licença.

01
Base do Sistema
Linux

Sistema operacional open source baseado em Unix. Alta estabilidade, segurança e flexibilidade incomparáveis para servidores corporativos.

  • Kernel estável — meses sem reinicialização
  • Alta segurança e controle granular de permissões
  • Open source — zero custo de licença
  • Debian 11 como distribuição da solução
02
Compartilhamento
Samba

Implementação do protocolo SMB/CIFS para Linux — compartilha arquivos com Windows e macOS de forma totalmente transparente para o usuário.

  • Protocolo SMB compatível com Windows e macOS
  • Autenticação individual por funcionário
  • Integração com domínios Active Directory
  • Logs de auditoria de todos os acessos
03
Sincronização
Rsync

Ferramenta de sincronização diferencial — transfere apenas o que mudou desde a última cópia, economizando tempo e largura de banda de rede.

  • Sincronização diferencial (somente as diferenças)
  • Agendamento automático via Crontab
  • Suporte a SSH, compressão e checksum
  • RPO (Recovery Point Objective) mínimo
